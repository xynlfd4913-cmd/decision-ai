# DualMind AI 产品化蓝图

## 1. 产品一句话

DualMind AI 不是“通用聊天机器人”，而是一个“人生决策双脑分析工具”。

用户输入一个纠结问题，系统同时给出：

- 理性脑：利弊、风险、选择路径、下一步行动。
- 感性脑：情绪理解、内心冲突、真实顾虑、安抚建议。
- 决策结论：不替用户做决定，但给出可执行的判断框架。

核心卖点不是 AI 更强，而是把 AI 回答做成“结构化决策产品”。

## 2. 为什么有机会

市面上的 ChatGPT、Claude、Gemini 都能做理性分析和情绪安慰，但通常混在一段回答里。用户需要自己整理。

DualMind AI 的差异点是固定产品结构：

- 左侧理性脑，负责冷静分析。
- 右侧感性脑，负责共情和人话解释。
- 底部决策卡，负责给出建议、风险等级和行动清单。

用户买的不是“AI 聊天”，而是“帮我看清选择”。

## 3. 目标用户

第一阶段只做 3 类高焦虑、高传播、高付费场景：

1. 职业决策：要不要辞职、转行、换城市、创业。
2. 情感决策：要不要分手、复合、继续投入。
3. 人生选择：要不要买房、投资、接项目、离开某段关系。

不要一开始做成万能工具。越泛，越难成交。

## 4. MVP 必须有的功能

### 首页

- 一个问题输入框。
- 三个快捷场景按钮：辞职、感情、人生选择。
- 一个明确按钮：开始双脑分析。

### 分析结果页

输出固定为 4 块：

1. 理性脑
   - 事实拆解
   - 利弊对照
   - 最大风险
   - 可执行建议

2. 感性脑
   - 你真正纠结的点
   - 情绪来源
   - 你可能没说出口的担心
   - 安抚和提醒

3. 决策卡
   - 建议方向：继续观察 / 可以行动 / 暂缓决定
   - 风险等级：低 / 中 / 高
   - 7 天行动清单

4. 分享卡
   - 生成适合小红书/朋友圈截图的摘要。
   - 用户愿意分享，才会带来自传播。

### 付费限制

- 免费用户每天 3 次基础分析。
- 付费解锁深度分析、历史记录、PDF/图片导出、更多场景模板。

## 5. 当前代码如何产品化

当前 `eam_model.py` 是一个自研模型实验框架，包含：

- HyperCubeBaguaTransform：自研注意力实验。
- EAMMultiFusionBlock：全局、序列、局部三路融合。
- SelfDevelopMemoryPool：短期/长期记忆池。
- DualSymbiosisBrain：理性/感性双脑结构。
- AvalancheSelfResetCtrl：训练中的参数重置实验。

但它现在没有训练数据和成熟语言能力，直接给用户用会生成乱码或无意义文字。

正确产品路线：

### 第一阶段

用稳定大模型 API 或本地成熟模型负责生成内容。

当前自研代码保留为：

- 品牌故事
- 技术储备
- 后续私有化模型研究
- 本地记忆系统原型

### 第二阶段

把 `DualSymbiosisBrain` 的思想产品化，而不是强行使用未训练模型：

- 理性脑 = 同一个模型 + 理性系统提示词
- 感性脑 = 同一个模型 + 共情系统提示词
- 决策脑 = 汇总两边输出，生成决策卡

### 第三阶段

再训练或微调自研 EAM 模型，用于：

- 用户历史偏好记忆
- 风格化输出
- 私有部署版本
- 轻量本地推理卖点

## 6. 技术架构建议

### MVP 技术栈

- 前端：Next.js / React
- 后端：FastAPI 或 Next.js API Routes
- 数据库：SQLite 起步，后续 PostgreSQL
- 支付：中国场景优先微信支付/支付宝；海外可 Stripe
- AI 层：先接稳定大模型，再逐步接入本地模型

### 核心接口

`POST /api/analyze`

输入：

```json
{
  "question": "我要不要辞职？",
  "scene": "career",
  "depth": "basic"
}
```

输出：

```json
{
  "rational": "...",
  "emotional": "...",
  "decision_card": {
    "suggestion": "暂缓决定",
    "risk_level": "中",
    "actions": ["先确认存款", "和上级谈一次", "投递 10 个岗位"]
  },
  "share_summary": "..."
}
```

## 7. 价格设计

先做低门槛，不要一开始卖太贵。

- 免费：每天 3 次基础分析。
- 9.9 元：10 次深度分析卡包。
- 19 元/月：每天 20 次分析 + 历史记录。
- 39 元/月：无限基础分析 + 深度报告 + 分享卡。
- 199/499 元：人工整理版深度决策报告，后续再做。

目标“每天 500 元”的现实路径：

- 9.9 元卡包：约 50 单/天。
- 39 元 Pro：约 13 单/天。
- 混合模型：30 个卡包 + 5 个 Pro，接近 500 元/天。

这不是保证收入，而是用于倒推流量和转化指标。

## 8. 增长漏斗

内容平台不要直接卖“AI 产品”，要卖“问题被看懂的体验”。

推荐内容公式：

问题 -> 双脑反差 -> 决策卡 -> 引导体验

小红书标题方向：

- AI 帮我分析要不要辞职，结果太真实了
- 我把分手问题丢给双脑 AI，它说中了我没说出口的点
- AI 让我先别冲动换城市
- 理性脑说别辞，感性脑却看出了我真正累的原因

转化路径：

内容曝光 -> 点击主页 -> 免费体验 -> 3 次限制 -> 深度分析付费。

## 9. 7 天执行计划

Day 1：做 MVP 页面原型，只支持 3 个场景。

Day 2：接入双脑提示词，跑通一次完整分析。

Day 3：加历史记录和次数限制。

Day 4：加分享卡导出。

Day 5：加付费入口和卡包逻辑。

Day 6：发布 10 条小红书、5 条抖音测试内容。

Day 7：看数据，只放大点击率和收藏率最高的主题。

## 10. 第一版不要做什么

- 不要先训练自研大模型。
- 不要做太多场景。
- 不要做复杂智能体工作流。
- 不要承诺医疗、法律、投资结果。
- 不要让 AI 替用户做最终决定。

第一版只验证一件事：用户愿不愿意为“结构化双脑决策分析”付费。

## 12. 最小可卖版本

第一版只要做到这 5 个点，就可以上线测试：

1. 输入问题。
2. 生成理性脑 + 感性脑。
3. 生成决策卡。
4. 免费次数限制。
5. 付费解锁深度分析。

等有真实用户和付费后，再把当前 EAM 自研模型慢慢接成“私有化、本地化、记忆增强”的高级卖点。
