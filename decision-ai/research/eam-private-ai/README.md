# EAM-Private-AI

#### 介绍
项目简介
本项目基于 “一加N双时间对象耦合”专利理论 与 八卦图数理逻辑 推演而来，构建了一套完整的私有化 AI 模型架构。模型可在本地运行，无需联网，所有数据主权归属用户本人。

理论根源
专利根基：“一加N双时间对象耦合”专利，由中国人申请，是本项目的理论基石。

算法哲学：核心注意力机制“四维八卦变换（HyperCubeBaguaTransform）”，由八卦图的阴阳爻变、卦象推演逻辑演变而来。

核心架构
模块	说明
HyperCubeBaguaTransform	四维八卦变换注意力，基于正交基状态池与 GRU 动态选择，使用曼哈顿距离替代传统内积
EAMTimeGateFFN	时序门控前馈网络，通过 GRU 生成动态门控信号
EAMMultiFusionBlock	三路特征融合模块，融合全局、序列、局部特征，含可学习残差系数
AvalancheSelfResetCtrl	雪崩自适应重置机制，定期重置部分网络参数，防止知识僵化
SelfDevelopMemoryPool	长短记忆分级池，自动迁移，支持持久化与增量学习
DualSymbiosisBrain	理性/感性双脑共生架构，交互生成并互相优化
